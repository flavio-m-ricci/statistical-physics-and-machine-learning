## Overview

This exercise studies how polynomial degree, training-set size and observation noise affect prediction accuracy. Models are fitted to synthetic data generated by a linear function and a degree-10 polynomial, then evaluated on independent test inputs both inside and beyond the training interval.

The implementation compares degrees 1, 3 and 10. The results illustrate the effects of model mismatch, noise sensitivity and extrapolation.

## Mathematical setup

The observations are generated as

$$
y_\mu=f(x_\mu)+\eta_\mu,\qquad
\eta_\mu\sim\mathcal N(0,\sigma^2),
$$

with independent Gaussian noise and uniformly sampled inputs. Here $\sigma$ is the noise **standard deviation**.

The two generating functions are

$$
f_A(x)=2x,\qquad
f_B(x)=2x-10x^5+15x^{10}.
$$

For each dataset, the fitted models are

$$
p_d(x)=\sum_{k=0}^{d}\theta_kx^k,
\qquad d\in\{1,3,10\}.
$$

The models therefore have 2, 4 and 11 coefficients, including the intercept. The script uses NumPy's `np.polyfit` to obtain polynomial fits and `np.polyval` to evaluate them.

## Experimental design

Each configuration is run separately for both generating functions:

| Configuration | Training points | Noise $\sigma$ | Training interval | Test points | Test interval |
|---|---:|---:|---|---:|---|
| 1 | 10 | 0 | $[0,1]$ | 20 | $[0,1.25]$ |
| 2 | 100 | 1 | $[0,1]$ | 20 | $[0,1.25]$ |
| 3 | 10,000 | 1 | $[0,1]$ | 100 | $[0,1.25]$ |

For each function and configuration, the script:

1. Generates one training sample.
2. Fits all three polynomial degrees to the same training observations.
3. Generates an independent test sample with the same noise level.
4. Plots the training and test observations alongside the fitted models and the underlying function.
5. Evaluates test errors over the full test sample and separately inside and outside the training interval.

Test inputs are randomly sampled from the specified interval; they are not a regular grid. The smooth curves in the figures use a separate grid of 500 plotting points.

## Error measures

For a nonempty subset $S$ of test inputs, the script evaluates

$$
\operatorname{MSE}_{\mathrm{test}}(S)
=\frac{1}{|S|}\sum_{\mu\in S}
\left[y_\mu-p_d(x_\mu)\right]^2
$$

and

$$
\operatorname{MSE}_{\mathrm{true}}(S)
=\frac{1}{|S|}\sum_{\mu\in S}
\left[f(x_\mu)-p_d(x_\mu)\right]^2.
$$

The first quantity compares predictions with the test observations, which include noise when $\sigma>0$. The second compares predictions with the noise-free generating function at the same test inputs.

The output names are:

| Output | Meaning |
|---|---|
| `MSE_test` | Error against observations over the full test sample |
| `MSE_true_func` | Error against the underlying function over the full test sample |
| `MSE_test_in`, `MSE_true_func_in` | Corresponding errors for $x\leq1$ |
| `MSE_test_out`, `MSE_true_func_out` | Corresponding errors for $x>1$ |

The script plots training fits but does not report a numerical training-set MSE. All reported MSE values are evaluated on test inputs.

## Results and interpretation

The following values are taken from [`simulation_results.txt`](simulation_results.txt) and rounded. They report `MSE_true_func` over the entire test interval, so they include extrapolation.

| Function | Training points | $\sigma$ | Degree 1 | Degree 3 | Degree 10 |
|---|---:|---:|---:|---:|---:|
| $f_A$ | 10 | 0 | $3.24\times10^{-33}$ | $2.33\times10^{-30}$ | $5.17\times10^{-14}$ |
| $f_B$ | 10 | 0 | 340.143 | 226.623 | $1.96\times10^{-8}$ |
| $f_A$ | 100 | 1 | 0.0324194 | 0.0635858 | 24,951.4 |
| $f_B$ | 100 | 1 | 1,012.63 | 733.992 | 45,915.3 |
| $f_A$ | 10,000 | 1 | $9.29\times10^{-5}$ | 0.00766063 | 1,303.21 |
| $f_B$ | 10,000 | 1 | 691.179 | 503.979 | 4.00378 |

For the linear function, degree 1 matches the generating model and gives the lowest error in all three saved configurations. Higher degree does not guarantee better predictions: with noisy data, the degree-10 model is especially unstable outside the training interval.

For the nonlinear function, degrees 1 and 3 cannot represent the generating polynomial exactly. The degree-10 model performs well in the noise-free sample, becomes highly sensitive to noise with 100 training points, and improves substantially with 10,000 points.

The distinction between prediction inside the training interval and extrapolation is essential. For $f_A$ with 10,000 training points, the degree-10 model has an error against the true function of approximately **0.000960 inside** the interval but **10,024.7 outside** it. A small error inside the training interval therefore does not establish reliable extrapolation.

These are results from one fixed-seed dataset per configuration, not averages over repeated experiments. The script does not estimate statistical error bars.

### Numerical limitation: degree 10 with 10 observations

A degree-10 polynomial has 11 coefficients. Fitting it to only 10 observations is an underdetermined problem: the observations do not uniquely identify all coefficients, even without noise.

This configuration is retained as part of the exercise. `np.polyfit` emits a `RankWarning` for the supplied noise-free cases, and its numerical solution should not be interpreted as unique recovery of the generating polynomial. High powers in the polynomial basis also make numerical conditioning relevant, especially when interpreting extrapolation.

## Files and execution

| Path | Contents |
|---|---|
| [`polynomial_regression.py`](polynomial_regression.py) | Data generation, fitting, plotting and MSE evaluation |
| [`simulation_results.txt`](simulation_results.txt) | Saved MSE values |
| [`figures/`](figures/) | Twelve saved plots |
| [`report.pdf`](report.pdf) | Student report |

From the repository root, install the dependencies and run:

```bash
python -m pip install -r requirements.txt
python exercises/01-polynomial-regression/polynomial_regression.py
```

Alternatively, from this exercise directory:

```bash
python polynomial_regression.py
```

The script runs all six function/configuration combinations. It writes outputs next to the script, overwriting `simulation_results.txt` and figures with matching names. With an interactive Matplotlib backend, close each figure window to continue to the next plot. For unattended execution, select a noninteractive backend such as `Agg` using the `MPLBACKEND` environment variable.

### Reproducibility

The script sets `np.random.seed(12345)` once before running the six simulations, in this order: $f_A$, then $f_B$, for training sizes 10, 100 and 10,000. Changing that order or running only part of the script changes the subsequent random samples.

A verification run using **Python 3.13.7, NumPy 2.3.3 and Matplotlib 3.10.6** reproduced the saved numerical output exactly and generated 12 separate figures. These are verified environment versions; `requirements.txt` does not pin versions, and numerical or rendering differences may occur with other environments.

The script is intended to be executed directly: importing it also launches the simulations and rewrites its outputs.
