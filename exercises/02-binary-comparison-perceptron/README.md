## Overview

This exercise studies a perceptron that compares two unsigned 10-bit integers. An analytically constructed reference classifier is checked against direct integer comparison, then compared with a randomly initialized classifier and two perceptrons trained from examples.

The experiments examine how learning changes the weights and how training-set size affects generalization.

## Mathematical setup

Each input is a vector of $N=20$ components,

$$
\boldsymbol S=(S_1,\ldots,S_{20}),\qquad S_i\in\{-1,+1\}.
$$

The first ten components encode the integer $n_T$, and the remaining ten encode $n_B$. Within each half, the most significant bit comes first. Binary digits 0 and 1 are represented by $-1$ and $+1$, respectively, so both integers range from 0 to 1023.

The target label is

$$
y=
\begin{cases}
+1,&n_T>n_B,\\
-1,&n_T\leq n_B.
\end{cases}
$$

For weights $\boldsymbol J$, the perceptron computes the field $h=\sum_{i=1}^{20}J_iS_i$ and predicts

$$
\widehat y=
\begin{cases}
+1,&h>0,\\
-1,&h\leq0.
\end{cases}
$$

A zero field is therefore assigned label $-1$.

### Reference weights

The reference classifier uses

$$
J_i^*=2^{10-i}\quad(1\leq i\leq10),\qquad
J_i^*=-J_{i-10}^*\quad(11\leq i\leq20).
$$

With this encoding, its field is $h^*=2(n_T-n_B)$. The prediction therefore implements the desired comparison, including label $-1$ for equal integers.

The implementation also provides an independent benchmark that decodes each half of the input into an integer and compares the two numbers directly.

## Experimental design

| Stage | Number of examples | Purpose |
|---|---:|---|
| Reference check | 10,000 | Compare reference predictions with direct integer comparison |
| Random classifier | 10,000 fresh examples | Evaluate one classifier with weights drawn from $\mathcal N(0,1)$ |
| Training | 500 and 2,000 | Train two separately initialized perceptrons |
| Final test | 10,000 fresh examples | Compare both trained models on the same independent test sample |

All input bits are sampled independently and uniformly. Training labels and test labels are generated by the reference classifier. Each trainable model starts with independent standard normal weights.

### Learning rule

For each misclassified training example, the weights are updated as

$$
J_i\leftarrow J_i+\frac{1}{\sqrt{20}}\,y_\mu S_i^\mu.
$$

Correctly classified examples do not produce an update. Training examples are visited in their original order on every pass, without shuffling. The training error is evaluated after each complete pass, and training stops when it reaches zero.

The script uses no fixed limit on the number of training passes.

## Error measures and weight plots

Classification error is the fraction of examples whose predicted label differs from the target label.

- **Training error** is measured on the dataset used to update the weights.
- **Test error** is measured on fresh examples after training.

The reference classifier is evaluated against direct integer comparison. The random classifier and trained models are evaluated against reference labels.

Weight plots show

$$
q_i=\mathrm{sign}(J_i^*J_i)\,\log_2|J_i|,
\qquad i=1,\ldots,20.
$$

The two input halves are plotted in different colors. This logarithmic representation requires nonzero weights; the script applies the transform directly.

For each training-set size, the script saves weight plots at initialization, at the first recorded training errors below 0.1 and 0.03, and at zero training error.

**The errors in the figure titles and filenames are training errors.** Final test errors are printed separately in the terminal.

## Main findings

The supplied experiment illustrates three main points:

- **Reference rule:** positional binary weights implement integer comparison exactly.
- **Learning:** both trained models reach zero training error, while errors on unseen inputs remain nonzero.
- **Generalization:** the model trained with 2,000 examples has a lower test error than the model trained with 500 examples in this run.

The [report](report.pdf) presents the detailed results and discussion. The script performs one run for each training-set size; it does not average over repeated initializations or estimate statistical error bars.

From the repository root, install the dependencies and run:

```bash
python -m pip install -r requirements.txt
python exercises/02-binary-comparison-perceptron/binary_comparison_perceptron.py
```

Alternatively, from this exercise directory:

```bash
python binary_comparison_perceptron.py
```

The script runs the full experiment, prints classification errors in the terminal and saves figures next to the script in `figures/`. It does not save a numerical results file. Figures with matching filenames are overwritten.

When run normally from a terminal with a graphical Matplotlib backend, the script pauses at `plt.show()` until the figure window is closed. For unattended execution, set the `MPLBACKEND` environment variable to `Agg` to save the figures without opening windows.

### Reproducibility

The script uses a single NumPy random generator initialized with `np.random.default_rng(seed=12)`. Reproducing the same random samples and initial weights requires preserving the full execution order.
