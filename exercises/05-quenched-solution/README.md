## Overview

This exercise investigates the quenched prediction for the generalization error of a teacher–student perceptron. The implicit analytical relation between the teacher–student overlap and the number of training examples per input dimension is studied through a parametric representation and two fixed-point formulations.

The implementation examines their convergence properties, develops an automatic procedure combining the two methods and compares the resulting theoretical generalization curve with the numerical results from Exercise 03.

## Mathematical setup

A student perceptron with $N$ binary inputs receives $P=\alpha N$ labeled examples generated by a teacher perceptron. According to the quenched computation, the typical student achieving zero training error has an overlap $R(\alpha)$ with the teacher satisfying

```math
\frac{R}{\sqrt{1-R}}
=\frac{\alpha}{\pi}I(R),
```

where

```math
I(R)=\int_{-\infty}^{\infty}
\frac{dv}{\sqrt{2\pi}}
\frac{\exp[-(1+R)v^2/2]}
{H(-\sqrt{R}\,v)}
```

and

```math
H(u)=\int_u^\infty
\frac{dx}{\sqrt{2\pi}}
\exp(-x^2/2).
```

The overlap determines the generalization error through

```math
\epsilon(R)=\frac{1}{\pi}\arccos(R).
```

Here $\alpha=P/N$ is the number of training examples per input dimension, while $R$ measures the alignment between the student and teacher weight vectors.

### Numerical evaluation of the integral

The integral $I(R)$ is evaluated using adaptive numerical quadrature from SciPy, with absolute and relative tolerances of $10^{-10}$.

To improve numerical stability, the implementation evaluates the logarithm of the Gaussian survival function using `scipy.special.log_ndtr`, avoiding the direct computation of very small probabilities.

The integral depends only on $R$, and previously computed values are cached using `functools.lru_cache` to reduce repeated numerical integration.

### Parametric representation

The implicit equation can be represented parametrically by choosing $t=R$:

```math
\bigl(\alpha(t),\epsilon(t)\bigr)
=
\left(
\frac{\pi t}{\sqrt{1-t}\,I(t)},
\frac{\arccos(t)}{\pi}
\right).
```

The numerical plot uses 100 values of $t$ between 0 and 0.999, avoiding the singular endpoint $t=1$.

At $\alpha=0$, the analytical solution is $R=0$, corresponding to $\epsilon(0)=0.5$.

## Fixed-point methods

To determine $R$ for a prescribed value of $\alpha$, the implicit equation is rewritten in two equivalent fixed-point forms:

```math
f_1(R,\alpha)
=
\frac{\alpha}{\pi}\sqrt{1-R}\,I(R),
```

```math
f_2(R,\alpha)
=
1-\frac{\pi^2R^2}{\alpha^2I(R)^2}.
```

For either function, the relaxed fixed-point iteration is

```math
R_{i+1}
=
(1-a)R_i+a\,f_j(R_i,\alpha),
\qquad j\in\{1,2\}.
```

The relaxation parameter $a$ controls the contribution of the fixed-point map at each iteration.

Iteration stops successfully when

```math
|R_i-f_j(R_i,\alpha)|<10^{-10}.
```

The solver checks that successive values are finite and remain in the physical range $0\leq R<1$. It reports failure if these conditions are violated or if 1,000 iterations are reached without convergence.

The second fixed-point formulation is not defined at $\alpha=0$, which is handled separately in the automatic procedure.

## Experimental design

### Prescribed convergence tests

Both fixed-point maps are tested using the following configurations:

| Map | $\alpha$ | $R_0$ | Relaxation $a$ |
|---|---|---|---|
| $f_1$ | 0.1, 5.0 | 0.5 | 0.5 |
| $f_2$ | 0.1, 5.0 | 0.5 | 0.5 |

For each case, the script saves a plot of $R_i$ against the iteration number $i$ to examine the convergence behavior.

### Parameter sweep

A broader numerical investigation explores the convergence of both maps over different target ratios, initial overlaps and relaxation parameters:

| Parameter | Values |
|---|---|
| $\alpha$ | 100 equally spaced values in $[0,10]$ |
| $R_0$ | 10 equally spaced values in $[0.01,0.99]$ |
| $a$ | 10 equally spaced values in $[0.1,0.9]$ |
| Convergence tolerance | $10^{-10}$ |
| Maximum iterations | 1,000 |

This gives 10,000 trials per fixed-point map.

For each trial, the script records the final overlap, convergence status, number of iterations and fixed-point residual.

The results are summarized by map, initial overlap and relaxation parameter. Configurations are ranked by decreasing success rate, then increasing mean residual and finally increasing mean iteration count among successful trials.

Success-rate heatmaps illustrate the dependence of convergence on $R_0$ and $a$.

### Automatic solution

Since neither fixed-point formulation is uniformly reliable over the investigated range, the automatic procedure combines both methods.

The procedure:

1. Computes the convergence success rate of each map as a function of $\alpha$.
2. Identifies the region where both maps converge for all tested initial overlaps and relaxation parameters.
3. Determines a switching value $\alpha_{\mathrm{switch}}$ from the midpoint of this common region.
4. Selects the most reliable configuration of $R_0$ and $a$ for $f_1$ below the switching value and $f_2$ above it.
5. Computes $R(\alpha)$ and the corresponding $\epsilon(\alpha)$ for 100 values of $\alpha\in[0,10]$.

The boundary $\alpha=0$ is handled analytically by setting $R=0$.

The final figure compares:

1. The analytical parametric curve.
2. The automatically computed fixed-point solutions.
3. The saved Exercise 03 numerical results for $N=20$ and update-noise variance $v=50$, plotted against $\alpha=P/N$.

Although `results_03/` also contains the $N=40$ numerical data, the current final plotting function reads only `N20_results_var50.txt`. The numerical comparison does not include uncertainty bars.

## Main findings

The saved results illustrate three main points:

- **Different convergence regions.** The two fixed-point maps exhibit complementary convergence behavior. The parameter sweep shows that no single tested configuration converges across the entire sampled range: the highest success rates are 84% for $f_1$ and 98% for $f_2$.
- **Reliable automatic solution.** Combining the two maps provides a convergent procedure over the investigated interval. All 100 saved automatic solutions converge, with fixed-point residuals below $10^{-10}$.
- **Agreement between theoretical representations.** The parametric and iterative calculations describe the same quenched relation. The Exercise 03 numerical results show a similar decrease in generalization error with increasing $\alpha$, providing a comparison between the theoretical prediction and finite-dimensional learning simulations.

The computed generalization error decreases from $\epsilon(0)=0.5$ to approximately $\epsilon(10)=0.0615$.

The differences between the quenched prediction and the numerical measurements should be interpreted in light of the finite input dimension and the particular noisy learning procedure used in Exercise 03.

### Execution switches

The main script uses Boolean switches near the beginning of `quenched_solution.py`:

| Switch | Operation |
|---|---|
| `PARAMETRIC_CURVE` | Save and display the parametric curve |
| `PLOT_R_CONVERGENCE` | Generate the four prescribed convergence plots |
| `SOLVE_EQUATION` | Run the full parameter sweep for both maps |
| `SHOW_RESULTS_EQUATION` | Read the sweep results and write raw and ranked summary CSV files |
| `SHOW_HEATMAPS` | Plot success-rate heatmaps from the raw summary |
| `SET_AUTOMATIC_PROCEDURE` | Determine the switching value, select configurations and save automatic solutions |
| `PLOT_FINAL_EPSILON` | Compare the analytical curve, automatic solutions and Exercise 03 data |

**With the current defaults, only `PLOT_FINAL_EPSILON = True`.** Running the script therefore regenerates the final comparison figure from the existing automatic-solution CSV and numerical data from Exercise 03. It does not repeat the convergence tests or parameter sweep.

To regenerate the complete analysis, enable the relevant switches.

The operations execute in the order shown in the script: parametric curve, convergence tests, parameter sweep, summary, heatmaps, automatic procedure and final comparison.

The convergence summary requires the two sweep CSV files. The heatmaps require the raw summary, while the automatic procedure uses the individual sweep results to determine the switching point and select configurations.

The final comparison requires `automatic_procedure_results.csv` and `results_03/N20_results_var50.txt`.

Figures and numerical results are saved relative to the exercise directory, and files with matching names are overwritten. Plotting functions call `plt.show()`, so a graphical Matplotlib backend may pause execution until figure windows are closed. For unattended plotting, set `MPLBACKEND=Agg`.

### Reproducibility

The quenched calculations, numerical integrations and fixed-point iterations are deterministic; they do not use random sampling.

Reproducing the stored outputs requires keeping the parameter grids, integration tolerances, convergence threshold, iteration limit and configuration-selection procedure unchanged.

The final comparison uses precomputed stochastic results from Exercise 03.

The numerical integration is computationally more demanding than the annealed calculation because each fixed-point evaluation requires evaluating $I(R)$. Caching previously computed integral values reduces repeated work.
