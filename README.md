## Overview

This repository collects my Python implementations, numerical experiments and reports for the *Statistical Physics and Machine Learning* course at Sapienza University of Rome.

The five exercises explore polynomial regression, model complexity, perceptron learning, generalization and the annealed and quenched approximations to perceptron learning. Each exercise README presents the mathematical setup, experimental settings, execution instructions and a short summary of the findings. The accompanying reports provide the detailed analysis.

## Exercises

### 01 — Polynomial Regression

Polynomial models of degrees 1, 3 and 10 are fitted to data generated by a linear function and a degree-10 polynomial. The experiments vary training-set size and observation noise, comparing predictions inside the training interval with extrapolation beyond it.

**Topics:** Polynomial fitting, model complexity, noise sensitivity and extrapolation.

[Exercise README](exercises/01-polynomial-regression/README.md) · [Report](exercises/01-polynomial-regression/report.pdf)

### 02 — Binary Comparison with a Perceptron

A perceptron compares two unsigned 10-bit integers. An analytically constructed reference classifier is checked against direct integer comparison, then compared with a random classifier and models trained on 500 and 2,000 examples.

**Topics:** Binary classification, perceptron updates, weight evolution and training versus test error.

[Exercise README](exercises/02-binary-comparison-perceptron/README.md) · [Report](exercises/02-binary-comparison-perceptron/report.pdf)

### 03 — Randomized Perceptron Learning

A teacher–student model introduces multiplicative Gaussian noise into the student's weight updates. The prescribed study uses noise variance 50 and input dimensions 20 and 40, estimating mean test errors and standard errors across 1,000 repetitions.

A **supplementary investigation** varies the update-noise variance for dimension 40, including the noise-free limit. These additional experiments are distinguished from the prescribed study.

**Topics:** Stochastic learning, generalization, statistical uncertainty and scaling with training-set size and dimension.

[Exercise README](exercises/03-randomized-perceptron-learning/README.md) · [Report](exercises/03-randomized-perceptron-learning/report.pdf)

### 04 — Annealed Solution to Randomized Perceptron Learning

The annealed approximation provides an implicit relation between the generalization error and the number of training examples per input dimension. The exercise studies this relation through a parametric curve and two fixed-point formulations with adjustable relaxation parameters.

A systematic parameter sweep compares the convergence properties of the iterative methods. The selected configuration is then used to compute the theoretical generalization curve, which is compared with the numerical results from Exercise 03.

**Topics:** Annealed approximation, fixed-point iteration, numerical convergence, relaxation methods and theoretical versus numerical generalization.

[Exercise README](exercises/04-annealed-solution/README.md) · [Report](exercises/04-annealed-solution/report.pdf)

### 05 — Quenched Solution to Randomized Perceptron Learning

The quenched computation provides an implicit relation between the teacher–student overlap and the number of training examples per input dimension. The exercise studies the corresponding generalization error through a parametric representation and two fixed-point formulations.

A systematic parameter sweep examines their convergence properties. An automatic procedure combines the two methods to compute the theoretical generalization curve, which is compared with the numerical results from Exercise 03.

**Topics:** Quenched approximation, teacher–student overlap, numerical integration, fixed-point iteration, convergence analysis and theoretical versus numerical generalization.

[Exercise README](exercises/05-quenched-solution/README.md) · [Report](exercises/05-quenched-solution/report.pdf)

## Installation and execution

The scripts use Python with **NumPy**, **Matplotlib**, **Numba**, **tqdm**, **pandas** and **SciPy**. From the repository root, install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run each exercise independently using the commands below, also from the repository root.

### Exercise 01

```bash
python exercises/01-polynomial-regression/polynomial_regression.py
```

This runs all six function/configuration combinations and saves twelve figures and the numerical MSE results.

### Exercise 02

```bash
python exercises/02-binary-comparison-perceptron/binary_comparison_perceptron.py
```

This runs the reference check, random classifier evaluation, both training experiments and the final test. Classification error rates are printed in the terminal, and weight plots are saved in `figures/` within the exercise directory.

### Exercise 03

```bash
python exercises/03-randomized-perceptron-learning/randomized_perceptron.py
```

**The current defaults run only dimension 40 at noise variance 50, with 1,000 repetitions, and do not generate figures.** The configuration switches control which dimensions are simulated and whether saved results are plotted.

The [Exercise 03 README](exercises/03-randomized-perceptron-learning/README.md#prescribed-study-and-saved-result-plots) explains how to run both dimensions or generate figures from the supplied tables without repeating the simulations.

To generate the supplementary variance-comparison figure from the eight supplied dimension-40 tables:

```bash
python exercises/03-randomized-perceptron-learning/plot_noise_sweep.py
```

This command reads existing results; it does not run the variance-sweep simulations.

### Exercise 04

```bash
python exercises/04-annealed-solution/annealed_solution.py
```

**The current defaults generate only the final comparison plot**, using the previously saved automatic-procedure results and the numerical data from Exercise 03. They do not rerun the convergence analysis.

The configuration switches in `annealed_solution.py` allow the parametric curve, fixed-point convergence plots, parameter sweep, convergence summaries, heatmaps and automatic procedure to be generated separately.

The [Exercise 04 README](exercises/04-annealed-solution/README.md) documents the execution modes, required intermediate files and numerical settings.

### Exercise 05

```bash
python exercises/05-quenched-solution/quenched_solution.py
```

**The current defaults generate only the final comparison plot**, using the previously saved automatic-procedure results and the numerical data from Exercise 03. They do not rerun the convergence analysis or the parameter sweep.

The configuration switches in `quenched_solution.py` allow the parametric curve, fixed-point convergence plots, parameter sweep, convergence summaries, heatmaps and automatic procedure to be generated separately.

The [Exercise 05 README](exercises/05-quenched-solution/README.md) documents the execution modes, required intermediate files and numerical settings.

## Outputs and reproducibility

| Exercise | Numerical output | Figures |
|---|---|---|
| 01 | [`simulation_results.txt`](exercises/01-polynomial-regression/simulation_results.txt) | [`figures/`](exercises/01-polynomial-regression/figures/) |
| 02 | Error rates printed in the terminal | [`figures/`](exercises/02-binary-comparison-perceptron/figures/) |
| 03 | Text tables in [`results/`](exercises/03-randomized-perceptron-learning/results/) | Saved in the same `results/` directory |
| 04 | CSV tables in [`results/`](exercises/04-annealed-solution/results/) | [`figures/`](exercises/04-annealed-solution/figures/) |
| 05 | CSV tables in [`results/`](exercises/05-quenched-solution/results/) | [`figures/`](exercises/05-quenched-solution/figures/) |

Exercise 04 also includes a `results_03/` directory containing copies of the saved numerical results from Exercise 03, used for the final comparison.

Exercise 05 likewise includes a `results_03/` directory containing copies of the saved Exercise 03 data and figures used for comparison.

Outputs are written relative to each script's location. Rerunning an experiment can overwrite files with matching names.

Exercises 01 and 02 display figures sequentially when run normally from a terminal with a graphical Matplotlib backend; close each figure window to continue. The main script for Exercise 03 displays its figures together when `PLOT_RESULTS = True`. For unattended plotting, set the `MPLBACKEND` environment variable to `Agg`.

The simulation scripts for Exercises 01–03 set fixed random seeds. Exercises 04 and 05 use deterministic numerical procedures and previously saved simulation results. The individual READMEs document the relevant settings, numerical parameters, saved outputs and any configuration changes needed to reproduce the experiments.
